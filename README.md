# 🧮 Projeto Calculadoras em Python

Este repositório contém uma coleção de scripts interativos em Python desenvolvidos para praticar lógica de programação, manipulação de variáveis, operações matemáticas e formatação de dados.

## 🚀 Funcionalidades Principais

O grande destaque do projeto é a **Calculadora de Restaurante**, que conta com recursos personalizados de soma, cálculo de impostos e troco:

* **Subtotais Separados:** Calcula de forma independente os gastos com refeições de adultos e crianças.
* **Toque de Criatividade:** Adicionei suporte para contabilizar a venda de **refrigerantes** e **sobremesas** no total geral da conta.
* **Cálculo de Imposto:** Aplica a taxa de imposto sobre as vendas informada pelo usuário de forma dinâmica.
* **Sistema de Pagamento e Troco:** Recebe o valor pago pelo cliente (aceitando tanto ponto quanto vírgula) e gera o troco correto de forma automática.
* **Formatação Monetária:** Exibe todos os valores organizados no padrão brasileiro (`R$ 1.000,00`).

## 📁 Arquivos Incluídos

* `calculadora_restaurante.py`: O script principal completo com os cálculos do restaurante, bebidas, sobremesas e impostos.
* `calculadora_refeicoes.py` e `calculadora_refeicoes_parcial.py`: Versões de desenvolvimento para controle de refeições.
* `calculadora_areas.py`: Script focado em cálculos geométricos.
* `.gitignore`: Arquivo de configuração para manter o repositório limpo, ignorando arquivos temporários (`__pycache__`).
